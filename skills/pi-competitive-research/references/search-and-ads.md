# Local search and public ads

Read this when discovering competitors or observing search visibility. A recorded search is a sample under specific conditions, not the whole local market.

## Build a small query set

Use the user's priority practice areas. A reasonable default is one broad query such as `personal injury lawyer [city state]`, then one query per priority case type, up to four queries total. Add a language query only if it addresses the brief. Exact-match quotes are unnecessary unless the user's question calls for them; record the exact text actually entered. Brand-name searches can verify identity but should not be mixed into general-category visibility counts.

Record a query ID, engine or tool, exact query, observed time/date, target geography, observer location if known, device/viewport if known, language, sign-in/personalization state if known, and result scope inspected. If a tool sets a search location, report the requested setting and how it was provided. A city in a query, an assistant's timezone, a VPN region, and the user's address are not proof of the search engine's observer location. Record `unknown` when appropriate.

If using a generic search API or AI search tool, call the result “discovery results from [tool].” Do not describe its list order as Google's organic position or infer local visibility from it. The website comparison can still proceed. User screenshots can support the results actually visible, with capture conditions provided by the user; their missing metadata stays unknown.

## Keep surfaces distinct

| Surface | What qualifies as evidence | What it does not establish |
| --- | --- | --- |
| Paid Search | Inspected search ad with a paid label, advertiser/domain, message, query and conditions | Budget, clicks, conversion rate, or full campaign targeting |
| Local Services Ads (LSA) | An identifiable LSA unit/profile in inspected results, with its visible label and details | Service quality, actual availability, or eligibility of firms that did not appear |
| Maps/local results | Inspected local pack or Maps results, with which view was used and any paid label recorded | One stable rank for the city or identical visibility from another location |
| Organic results | Inspected unpaid web results from the named engine under the logged query | Overall traffic, demand, or SEO quality |

Paid placements can occur in Maps or local modules. Label them “Sponsored Maps/local placement” and exclude them from unpaid local counts. Do not classify every “Sponsored” unit as LSA; if the format cannot be established, record “Paid placement, subtype unresolved.” AI answers, directories, and other modules can be recorded separately if relevant, never folded into an unexplained rank.

Default scope: the first results view for paid units and local pack, and the first ten unpaid web results if the actual page and pagination make them inspectable. For a dedicated Maps search, state the number of visible list entries inspected. Report a smaller visible scope honestly. Do not fabricate rank positions when the tool omits intervening results or modules. Preserve the observed URL or screenshot reference because a query URL alone does not preserve historical results.

Use the same queries and conditions across firms. For counts, state both appearances and inspectable samples within that channel, for example “present in 2 of 3 inspected local packs.” Missing channels are excluded from the denominator and listed explicitly. Do not call the fraction impression share, share of voice, or market share. Keep repeated queries at different locations/dates distinguishable; if summarizing them, explain the weighting.

## Inspect public creative separately

[Google Ads Transparency Center](https://adstransparency.google.com/) is an optional creative source. Search the verified firm or domain; record the advertiser identity, library URL/ad URL, date range, location/format filters, and access date. Preserve unresolved payer or agency relationships instead of assigning an ad to a firm on name similarity alone.

Google describes the center as a repository of ads served on its platforms, searchable by advertiser or website, with filters. Treat these as **library observations**, separate from observed local Paid Search. A library match is not evidence the creative ran for your query in your city; a failed search is not evidence of no advertising. Do not infer budget or demand from counts or ad longevity. [Google's ads transparency documentation](https://support.google.com/adspolicy/answer/13733850?hl=en).

Inspect visible ad content without clicking sponsored website, phone, directions, message, or contact actions. Verify the firm domain independently and navigate directly to ordinary pages. Other public ad libraries may be used if relevant and accessible; document the actual fields and limitations rather than assuming they expose the same data.

## Access limits and existing resources

When ads or Maps are not exposed, label that channel unavailable and finish the website comparison. If a reasonable alternate public source also fails, stop that branch. Do not purchase a tool, register for a trial, sign into an account, or bypass an access barrier as an implied part of the report.

Existing tools can assist a user who wants better local samples. [BrightLocal's free local SEO tools](https://www.brightlocal.com/free-local-seo-tools/) include a local results checker according to the vendor. Treat its outputs as third-party observations with the requested location, method, access date, and limitations; verify present access and any fees before use. It is optional and is not required for the core report.

The following primary sources explain why the limitations matter. Platform behavior can change; verify current documentation when a recommendation depends on it. Links checked September 25, 2026.

- [Google local ranking guidance](https://support.google.com/business/answer/7091?hl=en): local results depend on factors including relevance, distance, and prominence. A single observer's result is not a city-wide ranking.
- [Google LSA visibility troubleshooting](https://support.google.com/localservices/answer/12491365?hl=en): an LSA will not appear on every search. Nonappearance alone cannot establish nonparticipation.
- [Google Local Ads documentation](https://support.google.com/google-ads/answer/3246303?hl=en): paid local placements can appear in Search and Maps, and some interactions are chargeable. Identify paid labels and avoid ad actions during research.
